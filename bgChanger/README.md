# React Background Changer 🎨

A sleek, interactive background color manipulation application built with **React**, **Vite**, and **Tailwind CSS**. Effortlessly change the application's entire theme with a single click using a dynamically generated palette of colors.

![Background Changer Screenshot](./image.png)

## ✨ Features

- **Dynamic Color Injection**: Instantly alter the application's root background color through a robust color selection panel.
- **Data-Driven UI**: Buttons are dynamically generated by mapping over a centralized constants array, making the application effortlessly scalable for new colors.
- **Smart Typography**: Automatically adjusts text color inside buttons (e.g., turning text white when the "black" button is rendered) to ensure high contrast and accessibility.
- **Modern UI**: A responsive, fixed-bottom navigation bar styled with Tailwind CSS, featuring glassmorphism elements, smooth hover animations (`hover:scale-110`), and transition effects.

## 💡 Technical Challenges & Learnings

Building this application served as a practical exploration of React's core rendering cycles, inline styling mechanisms, and array iteration. Here are the specific engineering highlights built into the logic:

- **State-Driven Styling**: Mastered the integration of React's `useState` hook directly into the DOM's `style` attribute (`style={{backgroundColor: bgColor}}`). This pattern enforces React as the single source of truth for the application's visual state, ensuring instant and predictable re-renders.
- **Dynamic Prop Rendering & Conditional Logic**: Implemented inline ternary operations (`color == "black" ? "white" : "black"`) to enforce dynamic contrast ratios on button typography based on current iteration states.
- **Scalable Component Architecture**: Rather than hardcoding 18 distinct button components, I isolated the dataset into `src/constants/index.js` and dynamically mapped over the array (`ColorName.map(...)`). This approach drastically reduces boilerplate code, adheres to the DRY (Don't Repeat Yourself) principle, and ensures O(1) effort to add or remove color options in the future.
- **Tailwind Utility Mastery**: Leveraged complex Tailwind utility classes to build a responsive, floating control panel (`fixed bottom-0 left-1/2 transform -translate-x-1/2`) that remains anchored regardless of viewport size or background state.

## 🚀 Getting Started

Follow these steps to set up and run the background changer locally.

### Prerequisites
Make sure you have Node.js and a package manager (`npm` or `bun`) installed.

### Installation

1. Navigate to the project directory:
   ```bash
   cd bgChanger
   ```

2. Install the dependencies:
   ```bash
   npm install
   # or
   bun install
   ```

3. Start the development server:
   ```bash
   npm run dev
   # or
   bun run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.

## 📂 Key Architecture

- `src/App.jsx`: Houses the overarching `bgColor` state and serves as the primary view logic, dynamically injecting inline styles and iterating over the dataset to render controls.
- `src/constants/index.js`: Acts as the centralized database for the application, storing the `ColorName` array to ensure strict separation of concerns between data and UI logic.
