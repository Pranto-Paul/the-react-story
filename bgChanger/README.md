# BgChanger using React

A simple React application that changes the background color of the page based on the button clicked.

## Features

- Change background color with a click
- Works with vanilla CSS
- Uses Tailwind CSS for styling
- Clean and modern UI

## Installation

1. Clone the repository
2. Install dependencies
   ```bash
   npm install
   ```
3. Start the development server
   ```bash
   npm run dev
   ```

## Usage

Click the buttons to change the background color. The app uses `useState` to manage the background color and `useEffect` to update the DOM.

## Technologies Used

- **React**: For the UI components
- **Tailwind CSS**: For styling
- **Vanilla CSS**: For custom styles
